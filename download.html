Models are a separate choice.

The intended baseline is Windows x64 with a CPU engine. Model Setup recommends packs using hardware readings, browses Hugging Face and imports compatible local GGUF files. Council downloads require an explicit choice. Starter packs are a beginning rather than a fixed catalog; each model retains its own license.

Initial setup can use the internet for model and helper files. Local inference works after the required files are available. Optional network tools have separate requirements. GPU acceleration and other desktop platforms remain future work; universal hardware compatibility is not established.

The hardware families describe our development direction, including everyday computers and reused machines. They are not a verified compatibility list. Explore model choice to understand formats, available memory and licensing.

Your data stays yours.

The desktop uninstaller is designed to remove the application while preserving personal data. Data deletion is a separate decision, not an uninstall step. The replacement candidate's upgrade and preservation route is still being checked.

The internal Windows candidate is unsigned. Windows security checks and release-specific installation instructions will be documented with the published artifact. Signing alone does not complete setup, portability or release validation.

Access is not rented.

The local edition is free for individual use. Voluntary support funds development and testing; it does not unlock features, access, priority or influence. Institutional deployment and support may be paid, but they are not required for individual local use.
