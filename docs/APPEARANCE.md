# Website Appearances

The default is Sovereign Skeleton. Maya Radiance, Living Codex, Obsidian Ember and Calavera Nocturne are optional appearances. A choice uses the existing `zotheos_landing_theme` browser-storage key and carries across the website. No appearance preference leaves the device.

Calavera Nocturne combines midnight violet, magenta, jade and gold with original decorative calavera artwork drawn for ZOTHEOS. It is a visual option, not a claim that different Indigenous peoples share one tradition or symbol. The original mark, cited histories, film credits and release status remain unchanged.

## Source Owners

- `index.html` owns the landing page's controls and transitions. Its first-paint script matches `tools/nations/partials/bootstrap.js`.
- `tools/nations/partials/header.html`, `appearance.js` and `tokens.css` supply the learning pages and Theater. Existing token, markup and contrast gates also cover the fifth appearance.
- `static/appearance/calavera.css` and `calavera.js` own the decorative atmosphere. The two SVGs in that folder are original, self-hosted, script-free ornaments.
- `static/appearance/controls.js` and `palette.css` are copies generated by `tools/appearance_build.py`; edit their source partials instead.
- `static/appearance/game-theme.js` supplies the game's title/pause appearance controls. Seven existing menu-typography rules live in the shared companion stylesheet to preserve the engine's size limit. Game embedding therefore needs the appearance companion assets and their generated integrity attributes, as the website game page includes them.

Cached scripts use exact SHA-256 integrity and matching CSP hashes. The CSP tool rejects missing or mismatched integrity, duplicate source/integrity attributes, off-site sources, path traversal and assets redirected outside the literal static directory. It does not add a broad script origin or unsafe inline-script permission. Shared controls execute before the Theater's dependent controller and player. The download-page controller is deferred until its controls exist.

## Motion And Access

Living permits slow ambient motion and bounded fine-pointer reactions. Calm and Still keep the new atmosphere static. Reduced motion is a floor. Hidden pages and game entry stop background pointer work. Keyboard intensity changes use the same saved setting as pointer changes. No new sound or haptics are introduced.

The art is decorative and never takes focus. Reading text and source links retain their meaning and layout. Game ornaments appear only on desktop title/pause screens; gameplay and Nation cards keep their existing roles. Print and forced-color modes hide the ornaments. The fifth selection retains the existing keyboard radio pattern and minimum touch targets.

## Build And Verify

From the repository root, using the project's Python and Node toolchain:

```text
python tools/appearance_build.py
python game/build.py
python tools/csp_sync.py
python tools/nations_build.py --build-date YYYY-MM-DD
python tools/appearance_build.py --check
python tools/csp_sync.py --check
python -m pytest tools/tests
```

Use the intended build date; do not rewrite source-check dates to match a theme release. The appearance synchronizer repins only the explicitly named local companion assets in existing pages before the canonical builders verify their complete output. A failed integrity check must be fixed at the source rather than bypassed.

The existing Nation-page gzip, stylesheet, font and game-engine limits remain in force. Browser review must cover mobile and desktop, early paint, page-to-page persistence, all five choices, keyboard access, static modes and actual game rendering. Simulated event probes do not establish visual or assistive-technology conformance.
